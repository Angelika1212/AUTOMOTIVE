# AUTOMOTIVE
**Краткое описание:** Проект, предназначен для всестороннего изучения беспилотного автономного транспорта (в частности легковых авто). Направлен на освоение необходимых навыков/стека и поддержание собственного интереса к авто миру.

___
## **СТРУКТУРА ПРОЕКТА**
В папке cpp/scr находятся классы для "цифрового двойника" автомобиля, реализованные на С++.
В папке python/ будут располагаться файлы с классами, занимающиеся обработкой данных с сенсоров и датчиков виртуального автомобиля. 

cpp/scr/wheel.cpp - Колеса цифрового двойника автомобиля с набором базовых показателей.
cpp/scr/engine.cpp - Сердце авто и цифрового двойника - двигатель с разными вариациями (Бензиновый, Дизельный, Гибридный, Электрический).
cpp/scr/car.cpp - Сборка компонентов и отдельных частей в полноценный автомобиль.
